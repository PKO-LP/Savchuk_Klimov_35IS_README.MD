# Отчёт по разработке и ревью кода (Вариант 2. Пароль)
ТЗ
## Блок 1. Исходный код (Выдаточный материал)
*Роль: Программист*

Исходный вариант функции для проверки длины пароля, отправленный на ревью:

```python
def is_strong(password):
    if len(password) > 8:
        return True
```

---

## Блок 2. Код-ревью (Проверка)
*Роль: Ревьюер (Проверяющий)*

**Замечания по коду:**
1. **Логическая ошибка (Несоответствие ТЗ):** В ТЗ указано, что пароль должен быть *не меньше 8 символов* (то есть `>= 8`). В коде использовано строгое сравнение `> 8`. Из-за этого пароль ровно из 8 символов ошибочно посчитается слабым.
2. **Неполная логика (Отсутствие ветки False):** Если длина пароля меньше или равна 8, функция ничего не возвращает (неявно вернёт `None`), а по ТЗ должна возвращать `False`.
3. **Избыточность:** Конструкцию `if` можно сократить, возвращая результат логического сравнения напрямую.
4. **Вердикт:** Отклонить. Требуется исправление логических ошибок.

---

## Блок 3. Исправленный код
*Роль: Программист*

Исправленный и оптимизированный вариант функции, полностью соответствующий ТЗ:

```python
def is_strong(password):
    return len(password) >= 8
```
