# Отчёт по разработке и ревью кода (Вариант 5. Температура)

## Блок 1. Исходный код (Выдаточный материал)
*Роль: Программист*

Исходный вариант функции для проверки необходимости куртки, отправленный на ревью:

```python
def need_jacket(temp):
    if temp < 10:
        return False
```

---

## Блок 2. Код-ревью (Проверка)
*Роль: Ревьюер (Проверяющий)*

**Замечания по коду:**
1. **Логическая ошибка (Инверсия значений):** В коде при температуре ниже 10 градусов возвращается `False`. Согласно ТЗ, если температура ниже 10, функция должна возвращать `True` (куртка нужна).
2. **Неполная логика (Отсутствие ветки False):** Если температура 10 градусов и выше, функция ничего не возвращает (неявно вернёт `None`), а по ТЗ должна возвращать `False`.
3. **Избыточность:** Конструкцию `if` можно сократить, возвращая результат логического сравнения напрямую.
4. **Вердикт:** Отклонить. Требуется исправление логических ошибок.

---

## Блок 3. Исправленный код
*Роль: Программист*

Исправленный и оптимизированный вариант функции, полностью соответствующий ТЗ:

```python
def need_jacket(temp):
    return temp < 10
```
