# Отчёт по разработке и ревью кода (Вариант 4. Оценка)

## Блок 1. Исходный код (Выдаточный материал)
*Роль: Программист*

Исходный вариант функции для проверки баллов за зачёт, отправленный на ревью:

```python
def is_pass(score):
    if score >= 60:
        print("зачёт")
```

---

## Блок 2. Код-ревью (Проверка)
*Роль: Ревьюер (Проверяющий)*

**Замечания по коду:**
1. **Логическая ошибка (Несоответствие ТЗ):** Вместо возврата булева значения `True` функция использует вывод в консоль через функцию `print()`. По ТЗ функция должна именно *возвращать* (`return`) значения.
2. **Неполная логика (Отсутствие ветки False):** Если количество баллов меньше 60, функция ничего не возвращает (неявно вернёт `None`), а по ТЗ должна возвращать `False`.
3. **Избыточность:** Конструкцию `if` можно сократить, возвращая результат логического сравнения напрямую.
4. **Вердикт:** Отклонить. Требуется исправление логических ошибок и типа возвращаемого значения.

---

## Блок 3. Исправленный код
*Роль: Программист*

Исправленный и оптимизированный вариант функции, полностью соответствующий ТЗ:

```python
def is_pass(score):
    return score >= 60
```
