# Отчёт по разработке и ревью кода (Вариант 1. Номер телефона)

## Блок 1. Исходный код (Выдаточный материал)
*Роль: Программист*

Исходный вариант функции для форматирования и валидации номера телефона, отправленный на ревью:

```python
def make_phone(raw):
    try:
        text = str(raw)
        if "a" in text or "6" in text:
            return None
        number = "+" + text
        if len(number) > 11:
            return None
        return number
    except:
        print("ошибка")
    finally:
        print("проверка номера завершена")
        return number
```

## Блок 2. Код-ревью (Проверка)
*Роль: Ревьюер (Проверяющий)*

**Замечания по коду:**
1. **Логическая ошибка (Проверка букв):** Условие `if "a" in text` проверяет только одну букву `"a"`. По ТЗ запрещены любые буквы. Для корректной проверки нужно использовать метод `.isdigit()`.
2. **Логическая ошибка (Неверный запрет цифры):** Проверка `or "6" in text` ошибочно запрещает цифру 6 в номере телефона, что противоречит здравому смыслу и отсутствовало в ТЗ.
3. **Критическая ошибка (Нарушение длины):** Проверка `len(number) > 11` считает длину строки уже вместе со знаком `"+"`. Если пользователь ввёл 11 цифр (например, `79995553435`), то `number` станет `+79995553435` (длина 12), и корректный номер ошибочно отбросится. Проверять длину нужно у исходной строки цифр (`len(text) > 11`).
4. **Ошибка в блоке `except`:** Блок перехватывает исключения, но не возвращает `None`, как требует ТЗ в случае неверных данных (неявно вернётся `None`, но лучше прописать `return None` явно вместо `print`).
5. **Ошибка в блоке `finally`:** Конструкция `return number` внутри `finally` перезаписывает любые `return None`, которые сработали в блоке `try`. Из-за этого функция при любых условиях вернёт некорректный `number`. Блок `finally` должен содержать только `print()`.
6. **Вердикт:** Отклонить. Требуется исправление критических логических ошибок и работы с блоками `try/except/finally`.

## Блок 3. Исправленный код
*Роль: Программист*

Исправленный вариант функции, полностью соответствующий ТЗ:

```python
def make_phone(raw):
    try:
        text = str(raw)
        # Проверяем, что строка состоит только из цифр и их не больше 11
        if not text.isdigit() or len(text) > 11:
            return None
        return "+" + text
    except Exception:
        return None
    finally:
        print("проверка номера завершена")
```
