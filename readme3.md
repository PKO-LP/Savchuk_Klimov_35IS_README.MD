# Отчёт по разработке и ревью кода (Вариант 3. Скидка)

## Блок 1. Исходный код (Выдаточный материал)
*Роль: Программист*

Исходный вариант функции для расчета стоимости товара со скидкой, отправленный на ревью:

```python
def final_price(price):
    if price > 1000:
        return price - 10
```

---

## Блок 2. Код-ревью (Проверка)
*Роль: Ревьюер (Проверяющий)*

**Замечания по коду:**
1. **Логическая ошибка (Несоответствие ТЗ):** В ТЗ указано, что скидка применяется, если цена *1000 и больше* (то есть `>= 1000`). В коде использовано строгое сравнение `> 1000`. Из-за этого для цены ровно в 1000 скидка ошибочно не применится.
2. **Математическая ошибка:** Выражение `price - 10` вычитает из цены 10 единиц валюты, а не 10 процентов. Для уменьшения цены на 10% её нужно умножать на `0.9` (или вычитать `price * 0.1`).
3. **Неполная логика (Отсутствие ветки по умолчанию):** Если цена меньше 1000, функция ничего не возвращает (неявно вернёт `None`), а по ТЗ должна возвращать цену без изменений.
4. **Вердикт:** Отклонить. Требуется исправление логических и математических ошибок.

---

## Блок 3. Исправленный код
*Роль: Программист*

Исправленный вариант функции, полностью соответствующий ТЗ:

```python
def final_price(price):
    if price >= 1000:
        return price * 0.9
    return price
```
