# Отчёт по разработке и ревью кода (Вариант 2. PIN-код карты)

## Блок 1. Исходный код (Выдаточный материал)
*Роль: Программист*

Исходный вариант функции для проверки PIN-кода карты, отправленный на ревью:

```python
def check_pin(raw):
    try:
        pin = raw
        if len(pin) >= 4:
            return "ok"
        return "bad"
    except Exception:
        return "ok"
    finally:
        print("пин проверен")
        return "ok"
```

## Блок 2. Код-ревью (Проверка)
*Роль: Ревьюер (Проверяющий)*

**Замечания по коду:**
1. **Логическая ошибка (Проверка длины):** По ТЗ на вход должна поступать строка из *ровно 4 цифр*. Условие `if len(pin) >= 4` ошибочно пропустит PIN-код, состоящий из 5 и более символов. Должно быть строгое равенство `== 4`.
2. **Логическая ошибка (Отсутствие проверки символов):** Код никак не проверяет, что во входящих данных содержатся исключительно цифры. Буквы и специальные знаки по ТЗ запрещены, поэтому строку необходимо валидировать с помощью метода `.isdigit()`.
3. **Логическая ошибка в блоке `except`:** Если в блоке `try` падает ошибка (например, передано число вместо строки, и `len()` вызывает исключение), блок `except` ошибочно возвращает `"ok"`. В случае ошибки функция должна возвращать `"bad"`.
4. **Критическая ошибка в блоке `finally`:** Конструкция `return "ok"` внутри блока `finally` принудительно перезаписывает любой результат работы функции. Из-за этого функция *всегда* возвращает `"ok"`, даже если PIN-код был некорректным и сработал `return "bad"`. Блок `finally` должен содержать исключительно `print()`.
5. **Вердикт:** Отклонить. Требуется исправление критических логических ошибок, валидации символов и работы со структурой `try/except/finally`.

## Блок 3. Исправленный код
*Роль: Программист*

Исправленный вариант функции, полностью соответствующий ТЗ:

```python
def check_pin(raw):
    try:
        pin = str(raw)
        # Проверяем, что строка состоит только из цифр и её длина ровно 4
        if pin.isdigit() and len(pin) == 4:
            return "ok"
        return "bad"
    except Exception:
        return "bad"
    finally:
        print("пин проверен")
```
